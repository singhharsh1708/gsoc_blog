Diagram house style

Internal referenceCopy-paste templates

Three reusable diagram templates for technical posts. Inline SVG, no JS, theme-aware. Copy the snippet beneath each example and adjust the labels for your post.

The visual language is consistent across all three: indigo for generic abstractions, green for performance wins, amber for debugging and regressions, red for failing CI or numerical instability.

1 · Architecture diagram

For solver hierarchies, tableau abstractions, dispatch flow, and any "bespoke vs generic" comparison. This is the signature visual.

Source

2 · Debugging timeline

For CI investigations, regression hunts, convergence debugging. Vertical flow, color-coded by stage.

Source

3 · Benchmark comparison

For allocations, runtime, timestep counts, convergence. Horizontal bars beat vertical for two-metric comparisons.

Source

Authoring conventions

  • Dimensions: always use viewBox; never hard-code width/height on the <svg>.
  • Colors: reference var(--c-abstraction), var(--c-perf), var(--c-debug), var(--c-instability) — never hard-coded hex.
  • Text: use the .diag-label, .diag-mono, .diag-caps, .diag-num classes — don't set font properties inline.
  • Captions: every figure gets <figcaption> with <span class="fig-num">Fig N.</span> prefix.
  • Accessibility: add role="img" and a descriptive aria-label to every diagram <svg>.
